## 4. `demo_rows`

```python
def demo_rows(tok: ByteBPETokenizer, text: str) -> tuple[list[tuple[str, int]], str, bool]:
    ids = tok.encode(text)
    pieces = tok.pieces(text)
    decoded = tok.decode(ids)
    return list(zip(pieces, ids)), decoded, decoded == text
```
- **1つの文**について3つの手順をする:
  1. `ids = tok.encode(text)` — 番号。
  2. `pieces = tok.pieces(text)` — 読める断片(Day 6.1。不完全な文字は `<xx..>` の16進数で出る)。
  3. `decoded = tok.decode(ids)` — 番号から作り直した文。
- 3つを返す:
  - `list(zip(pieces, ids))` — `(断片, ID)` の組、例:`[("営業部", 412), ("の", 380), ...]`。`zip` は2つのリストを位置ごとに組にする。`pieces()` 自身が `encode` を通るので、`pieces` と `ids` は同じ長さ。
  - `decoded` — 戻した文。
  - `decoded == text` — 入力と同一なら `True`。
- 戻り値の型 `tuple[list[tuple[str, int]], str, bool]` は、「(文字, 番号)の組のリスト、文字列、真偽値」の意味。

## 5. `main`

```python
def main() -> int:
    if hasattr(sys.stdout, "reconfigure"):
        sys.stdout.reconfigure(errors="replace")
    ap = argparse.ArgumentParser(description="Day 7 demo: text -> pieces -> numbers -> text.")
    ap.add_argument("--text", action="append", help="sentence to show (repeatable); default: built-in examples")
    ap.add_argument("--tokenizer", type=Path, default=REPO_ROOT / "data/tokenizer/tokenizer.json")
    ap.add_argument("--out", type=Path, default=REPO_ROOT / "docs/DAY7_TOKENIZER_DEMO.md")
    a = ap.parse_args()
    tok = ByteBPETokenizer.load(a.tokenizer.resolve())
    sentences = a.text or list(DEFAULT_SENTENCES)
```
- コンソールの安全対策の行は前と同じ。短いスクリプトなので、引数のパーサーは `main` の中に書いてある。
- `--text` と `action="append"`:`--text "..."` を書くたびに、リストに文が1つ増える。1つも指定しなければ、`a.text` は `None`。
- `--tokenizer`(Day 6のファイル)と `--out`(書き出すMarkdownファイル)は、初期値付きの `Path` オプション。
- トークナイザーを読み込む。
- `sentences = a.text or list(DEFAULT_SENTENCES)` — 自分の文を指定していればそれを使い、そうでなければ(`None`)組み込みの5つを使う。(`or` は、最初の値が空や None のとき、2つ目を選ぶ。)


- `all_ok` — `True` から始まり、1つでも文が元に戻らなければ `False` になる。

```python
    for text in sentences:
        rows, decoded, ok = demo_rows(tok, text)
        all_ok &= ok
```
- 各文について `demo_rows` を実行する。`all_ok &= ok` は `all_ok = all_ok & ok` — 論理AND:`ok` が1度でも `False` になれば、`all_ok` は `False` のまま。

```python
        print(f"\nInput   : {text}")
        print(f"Pieces  : {' / '.join(p for p, _ in rows)}")
```

  - 戻した文。そして「入力と同じか」の `YES/NO` と、トークン数。

```python

            "",

```

  - 番号のリストと、太字の `yes/no` 付きの戻した文。
- `*( ... )` はジェネレーターをリストの項目に展開する(Day 4〜7と同じ技)。

## 7. 知っておくと良い小さなこと

- **Markdownの表の中の特殊文字。** 文に `|`(パイプ)や改行が含まれると、保存したMarkdownの表が崩れて見えることがある。組み込みの例には含まれていない。
- **必要なのはトークナイザーだけ。**トークンファイルは使わず、Day 6が終わればすぐ動く。
- **「実際の出力だけ」。**報告書にはトークナイザーが出したものがそのまま入るので、学校の作業計画の良い証拠になる。
- **`--machine` もログも無し** — SHA-256や時間は記録しない。それには `day7_encode_corpus.py` を使う。
