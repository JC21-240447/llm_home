## 今の Day 4 の内容と、その理由

最初の計画は「約40の文型で、会社の文を約20万行」でした。チームは、目的により合ったものを作りました:

| 計画 | チームが作ったもの |
| --- | --- |
| 約40の文型 | **60の質問タイプ** に **301の文型**(1タイプに約5つの言い回し) |
| 文、会話、質問 | 社員データについて社員が聞くような **質問だけ** |
| 約20万行 | **169,727 の重複のない質問**(1文型につき最大2,000) |

行数は少なく、文型は多い理由: 量より多様さが大事だからです。40の文型から20万行を作ると、同じ40の形の文が何千回も繰り返されます。301の文型なら、モデルはずっと多くの聞き方を学べます。1文型2,000という上限は、1つの文型がコーパスを埋め尽くすのを防ぎます(1つのタイプだけで169万問を作れてしまうため)。

今日の Day 4 は、**チームの生成プログラムを自分で実行し、チームのコーパスがまったく同じに再現されることを証明し、すべての部分を理解して** 教授に説明できるようにすることです。

### 私がすでに確認したこと

`DB.xlsx`(50行の表)は添付されていなかったので、コーパスに出てくる氏名と社員番号から代わりの表を作り、それで生成プログラムを実行しました:
- `patterns.csv`、`question_types.csv`、`columns.csv`: チームのファイルと **1バイトも違わない**。
- 質問は 169,727問で、チームのコーパスと同じ数。
- 300の文型のうち289が、チームとまったく **同じ質問** を作った。違った11はすべて人の名前を含む文型で、私の代わりの表では名前の並び順が違うため、ランダムな選択が別の名前に当たった。

本物の `DB.xlsx` を使えば、コーパス全体が1バイトも違わずに再現されるはずです。それが今日の一番の確認です。

## Step 4. 生成プログラムを理解する(レビューと、教授向けの資料のため)

VS Code で `data\source\make_questions.py` を開き、この章と並べて読みます。行番号はそのファイルのものです。

### 4.1 入力: すべてチームのファイルから

| 入力 | 生成プログラムが使うもの |
| --- | --- |
| `src_1.txt`、`src_2.txt` | 文型 |
| `用語集.csv` | 用語集(92行目で読む) |
| `同義語辞書.csv` | 標準用語ごとの言い換え(93〜95行目)。例: 大阪 → 大阪支社 |
| `DB.xlsx` | 部署と勤務地の値、50人の氏名と社員番号(96行目と107〜114行目) |

外部の文章は使いません。作られる質問の言葉は、すべてこれらのファイルか、コードに書いた小さな語のリスト(例: 高い/低い)から来ます。

### 4.2 文型の書き方(`src_*.txt`)

```text
#T01|条件で一覧
{属性}の社員を一覧で見せてください。||
{属性}の社員を全員教えてください。||
```

- `#T01|条件で一覧` は質問タイプの始まりで、IDと名前です。
- その後の各行が1つの文型です: `文|列グループ|2つ目の列グループ`。数値の列を使わない文型では、グループは空です。
- `load_patterns()`(232〜245行目)がファイルを順に読み、P001、P002、… と番号を付けます。これで301の文型になります。
- `{ }` の中の言葉は、埋める **スロット** です。`slots.csv` に、すべてのスロットとそのルールが書いてあります(チームの確認用に作ったもの)。

### 4.3 スロットに入る言葉と、自然さのルール

- **数値の列**(47〜71行目、クラス `Col`): 列ごとに、言い方(年収 / 年俸 / 年間給与 / 年間収入)、実際のデータの範囲に合った比較の値(400万円〜800万円)、形容詞(年収は 高い/低い、勤続年数は 長い/短い)、疑問詞(いくら、何歳、何年)、意味のある集計(お金には合計を使うが、年齢には使わない)を持ちます。`columns.csv` はこの表を書き出したものです。
- **列グループ**(73〜81行目): 文型は、どの種類の列が合うかを指定します。例えば 大小(高い/低いが言える列)や 金額(お金だけ)。だから「年齢の合計」を聞く文型はできません。
- **部署と勤務地の言葉**(`value_words`、98〜105行目): 標準の値と、その同義語のうち「{X}の社員」で自然に読めるものだけ。「の」を含む言い換えや、「課・チーム・支店」などで終わるものは使いません。
- **その他のスロット**(`SLOT_DOMAINS`、153〜177行目): 役職、性別、休職の理由、配偶者の有無、年、月、年代、人数。
- **ペア**(`PAIR_DOMAINS`、178〜185行目): 2つの異なる値。比べる2つの部署や、終わりの年が始まりの年より後になる年の範囲など。

### 4.4 1つの質問を作る(`render`、271〜288行目)

1. 各スロットを、選んだ言葉で置き換える。
2. 決まった自然さのルールを当てはめる:
   - 「性別別」は「男女別」にする。
   - 「課長の社員」は「課長」にする。
   - 「性別が女ではない」は「女性ではない」にする。
3. あり得ない組み合わせを捨てる: 同じ列を2回使うもの、名前で指定した人にその人の名前を聞くもの。
4. 埋まっていないスロットや、おかしなつながり(「のの」「社員の社員」「平均平均」)があれば、**プログラム全体を止める**。壊れたコーパスが黙って書き出されることはありません。

各質問は **ラベル** と一緒に保存されます: 文型、質問タイプ、スロットに入った値を、小さな JSON の文字列にしたものです。ラベルがあるので、すべての質問を確認でき、例(`samples.csv`)を見直せます。ラベルは学習用の文章には入りません。

### 4.5 数えることと、バランス(`count` と `generate`、290〜320行目)

- `count()` は、各スロットの選択肢の数を掛け合わせます。すべての文型を合わせると、**2,941,425** 通りの質問が作れます。とても偏っていて、169万問作れるタイプもあれば、5問しか作れないタイプもあります。
- `generate()` は、1文型につき最大 N 問を取ります(`--corpus 2000` なら N = 2000):
  - 作れる質問が 3 × N 以下なら、全部作ってシャッフルし、N 問残す。
  - それより多ければ、異なる質問が N 問集まるまで、ランダムに組み合わせを選ぶ。
- ランダムな部分はすべて **シード 42** の1つの乱数生成器を使うので、同じ入力からはいつも同じコーパスができます。Step 3 で証明するのはこのことです。

### 4.6 文型をまたぐ重複(354〜365行目)

2つの文型が同じ文を作ることがあります。生成プログラムは最初のものだけを残します。そのため文型 **P171** には質問が1つも残りません: P171 が作れる文(例:「部門ごとの月額給与の最高額を教えてください。」)は、すべて前にある文型 **P026** も作るからです。失われる文はありませんが、これらの文がどの質問タイプに属するかは、チームが決めるべきです。

### 4.7 出力

| ファイル | 内容 |
| --- | --- |
| `patterns.csv` | 301の文型: ID、タイプ、文体(丁寧 / くだけた / 短い)、文、列グループ、作れる質問の数 |
| `question_types.csv` | 60のタイプと、文型の数、合計 |
| `columns.csv` | 4.3 の列ごとのルール |
| `samples.csv` | 文型ごとに5つの例。チームの確認用 |
| `questions.csv` | コーパス: 質問、文型ID、タイプID、ラベル |

## レビューで話すポイント

- **なぜ手で書かずに自動で作るか:** モデルには何千もの例が必要です。16人で手書きするには多すぎ、手書きの文は偏ります。人が書いた文型と自動の当てはめで、量と管理を両立できます。
- **なぜ言葉を自分たちのファイルだけから取るか:** 著作権の問題がなく、モデルが学ぶ言葉はすべて用語集で定義した言葉になるから。
- **なぜ 60タイプ × 約5つの言い回しか:** 1つのタイプは1種類の質問です。1タイプに複数の言い回しがあると、違う言い方でも同じ意味になることをモデルが学べます。Day 5 では、これを使って、見たことのない言い回しでテストします。
- **なぜ文型ごとに上限を設けるか:** 上限が無いと、169万問作れる1つのタイプがコーパスの大半を占めてしまうから。
- **なぜ自然さのルールをコードに入れるか:** プログラムのルールは 169,727 問すべてに当てはまります。人が確認できるのは一部だけです。
- **再現性:** 固定したシード、固定した入力、チームのファイルとの1バイト単位の比較。それを実行ログに記録する。
- **正直な限界:** 言い回しの多様さはチームの文型の範囲までで、人は50行の表から来るので、名前が繰り返し出てくる。
