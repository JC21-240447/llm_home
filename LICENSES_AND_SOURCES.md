# Licenses and sources

Rule: only the four source types below are allowed. No Wikipedia. If a source is unclear, it is skipped.

| Allowed type | Condition |
| --- | --- |
| Team-written text | Original wording; author recorded |
| Synthetic text | Generated by our own scripts from our glossary and patterns |
| Books | Only if copyright has expired (author died 70+ years ago, or marked public domain) |
| Japanese laws and regulations | Official source; download terms checked and recorded |
